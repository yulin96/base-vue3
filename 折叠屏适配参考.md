## iPhone Duo 浏览器可用尺寸

CSS px；“初始 → 滚动后”为地址栏显示与收起后的高度。来源是作者自有真机采样：2026-10-26～27，iOS 27.1、Safari 27.0、Chrome 157、默认设置。仅代表该环境。[原始测量](https://chadworks.co/iphone-duo-viewport-sizes/)

| 浏览器 | 屏幕 / 状态          | 宽度 | 高度：初始 → 滚动后 |
| ------ | -------------------- | ---- | ------------------- |
| Safari | 外屏竖屏             | 382  | 580 → 598           |
| Safari | 外屏横屏             | 594  | 368 → 386           |
| Safari | 内屏竖屏             | 669  | 871 → 900           |
| Safari | 内屏横屏             | 951  | 589 → 618           |
| Safari | 内屏横屏分屏，单窗口 | 385  | 571 → 589           |
| Chrome | 内屏竖屏             | 669  | 755 → 835           |
| Chrome | 内屏横屏             | 871  | 553 → 633           |

该测量中，分屏仅支持内屏横屏；Safari 的 `screen.width/height` 始终报告外屏尺寸，应按页面实际视口调试。[测量依据](https://chadworks.co/iphone-duo-viewport-sizes/)
