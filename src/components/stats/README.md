# 本机统计面板

在根组件挂载一次 `<StatsPanel />`（导入 `@/components/stats/panel.vue`）。按 P 显示，再按 P 隐藏；输入区域和组合快捷键不触发，失焦/进入后台隐藏。手机可用 `v-model` 对接项目现有入口，组件不提供常驻按钮。

组件沿用项目根字号，不设置画布尺寸。默认字号 3rem，700px 及以下窄屏为 2.4rem 并收紧卡片间距，可在 html/body 上用 `--interaction-stats-font-size` 覆盖。面板位于左上角，分为今日卡片、累计卡片和历史表格，按实际事件动态生成。单项铺满，多项自动换行；历史数据不折叠，面板内部纵向滚动，窄屏表格可横向滚动。

各事件分别展示今日/累计，不将不同事件相加作为人数或总计。按天明细保留所有事件，没有发生的事件显示 0。清除全部仅清除本机当前统计，底层仍先完整归档，失败保留原数据；不会清除其他活动、历史归档或云端统计。

默认读取现有本地统计；业务继续调用 `recordInteractionStat(event)`。可通过 `source` 注入独立本地数据源。

`pnpm type-check` 检查类型。
